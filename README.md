# Tavo · Варианты для меня — расширение для SillyTavern

Панель под последним сообщением бота: карусель вариантов для **персонажа игрока** — его действия, мысли,
эмоции. Игрок — отдельный человек от бота и может быть совсем в другом месте; варианты держат его POV.
Кнопка **«✍️ так и сделаю»**: пишет полноразмерный ход игрока в его стиле → постит как сообщение юзера →
генерит реакцию бота. Реролл — «🔄 другие варианты».

Это порт второй плашки из Tavo (пара к «Идеи для сюжета» — можно ставить одну или обе, они стекаются
под сообщением и не конфликтуют: разные namespace и ключи хранения).

## Как работает генерация
- **Варианты** — `generateRaw` (мета-задача вне чата, промт жёстко держит POV игрока по имени персоны).
- **Ход игрока** — `generateRaw` с инструкцией писать ЗА игрока полноразмерный пост, результат постится
  как сообщение юзера.
- **Реакция бота** — `generateQuietPrompt` в «громком» режиме (полный контекст чата + пресет), результат
  дописывается как сообщение персонажа.

Варианты и состояние «свёрнуто/развёрнуто» хранятся в `extra` сообщения — переживают перезаход.
По умолчанию панель **свёрнута**, клик по заголовку разворачивает.

## Установка (вручную)
1. Скопируй **всю папку** `st-tavo-me` в `SillyTavern/data/<твой-логин>/extensions/`
   (туда же, куда ставила `st-tavo-ideas`).
2. Обнови SillyTavern в браузере (F5).
3. Под последним ответом бота появится свёрнутая плашка «🎭 варианты для меня»
   (если стоит и первая — они встанут друг под другом).

Проверка: Extensions → «Tavo · Варианты для меня» в списке; в консоли (F12) строка `[tavo-me] загружено`.

## Настройки (вверху `index.js`)
- `VARIANTS_COUNT` — сколько вариантов (по умолчанию 5);
- `CONTEXT_MESSAGES` — сколько последних сообщений уходит модели как транскрипт (по умолчанию 12).
